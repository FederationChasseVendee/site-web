question: "Est-ce que ma validation départementale est suffisante pour chasser dans les communes limitrophes des départements voisins ?"
answer: "La possibilité de chasser sur les communes limitrophes pour les validations départementales est supprimée. Cependant, l’article R.423-20 du Code de l’Environnement prévoit désormais que « Le versement de la redevance cynégétique valide le permis pour le département dans lequel la validation a été accordée et, pour les territoires de chasse détenus par le même détenteur, pour leur partie contigüe située dans le département limitrophe."
